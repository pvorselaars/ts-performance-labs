# Lab log

Copy the template per attempt. It looks like busywork; it isn't. The value is in the **hypothesis** and **surprise** lines - that's where
your intuition actually gets calibrated. Be honest about wrong guesses; a log that only records the guesses you got right isn't teaching you anything.

```
## L?-?? name, date

#### Prediction

#### Baseline
? ms / ? MB allocated / (retained ? MB, if the exercise gates it)

#### Profiler + mode

#### What I saw

#### Hypothesis

#### Change made

#### Result

#### Surprise

#### Hints used
0 / 1 / 2 / 3

#### Could I explain it to someone else in 2 minutes?

#### Where would this bite in a real system?

#### Break my own fix

```
