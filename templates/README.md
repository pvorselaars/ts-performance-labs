# Templates

Two blank forms, copied per attempt — never edited in place:

- **`LAB-LOG.md`** — one entry per exercise attempt: baseline, hypothesis (written before you touch code), what changed, result, and the surprise. See the top-level [README.md](../README.md)'s "How to work an exercise" for when to fill this in.
- **`POSTMORTEM.md`** — one write-up per boss fight and capstone (Level 7, and the Angular capstones), written *before* reading the solution. A blameless format: describe the system, not yourself.

Filled-in examples of both — so you can see what "done" looks like before you're the one producing it — are in [docs/worked-example/](../docs/worked-example/README.md): [LAB-LOG-example.md](../docs/worked-example/LAB-LOG-example.md) and [POSTMORTEM-example.md](../docs/worked-example/POSTMORTEM-example.md).
